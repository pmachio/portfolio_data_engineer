# Introducción

Distintas imagenes de dockers para incluir metricas de tecnologias de BigData en un Dashboard de Grafana.

Nos hemos basado en el proyecto de [Luca Canali](https://github.com/cerndb/spark-dashboard/tree/master)

Cada carpeta tiene una adaptación desde el original

- /original -> Codigo Original, que es para recuperar metricas de Spark
- /hbase_metrics -> Añade métricas para HBases
